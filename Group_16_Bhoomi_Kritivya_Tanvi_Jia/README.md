## 🎯 Authorized Research Title
> **"How can an AI-driven VR mass-casualty triage simulation improve START protocol categorization accuracy and reduce assessment latency for emergency medical trainees under dynamic industrial hazard conditions?"**

### Academic Standard & Foundation
* **Governing Standard:** START (Simple Triage and Rapid Treatment) algorithm: RPM (Respiration, Perfusion, Mental Status) branches into Red, Yellow, Green, Black. Under-triage leads to preventable mortality; assessment must take < 60s/victim.
* **Scientific Scope:** Refined dependent variables to START categorization accuracy (%) and assessment latency in seconds; specified dynamic industrial hazard conditions (secondary smoke, gas leaks).
