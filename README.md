## Thematic Research Clusters

The eighteen cohort projects are structured into six coherent engineering domains:

1. **Spatial Acoustics, Voice & Perception:** Group 01 (Acoustic Raycasting), Group 18 (Multiplayer Spatial HRTF Voice).
2. **Clinical, Behavioral & Adaptive VR:** Group 15 (Bioadaptive Acrophobia Exposure), Group 16 (Mass Casualty Incident START Triage).
3. **Computer Vision, Gestures & Navigational AR:** Group 06 (ArUco Multi-Storey Wayfinding), Group 08 (Campus Checkpoint AR), Group 10 (Fiducial Freehand Review), Group 11 (Smart AR Kiosk & Handoff).
4. **Cybersecurity, Social Engineering & Biometrics:** Group 04 (Security Escape Room), Group 09 (Adaptive Phishing Scenarios), Group 12 (Immersive Threat Retention), Group 13 (Kinematic Biometric Auth), Group 17 (Physical Security Audit).
5. **Human-Robot Interaction & Remote Teleoperation:** Group 14 (High-Latency Predictive Ghost Rover).
6. **Stress Simulation, Accessibility & Logistics:** Group 02 (Nighttime Sensory Stress), Group 03 (Hostel Fire Egress), Group 05 (Voice NLP Assistive VR).

## Pedagogical Architecture & Quality Framework

### 1. Coupled Interface Scaffolding ($A \to B \to C$)
Each group workspace features modular C# scripts structured with explicit architectural dependencies:
- **Module A:** Environmental, sensor, or network input pipeline.
- **Module B:** Core spatial interaction, physical constraint solver, or behavioral adaptation engine.
- **Module C:** Continuous spatial telemetry logger and empirical benchmark exporter.
Each student role includes explicit `# TODO [Roll - Name]` scaffolding blocks linking theoretical mathematical formulations directly into OpenXR runtime hooks.

### 2. Rigorous Literature Curation Standard (2 Seminal : 4 Recent)
Every group dossier features exactly six peer-reviewed foundational papers indexed in premier IEEE, ACM, Springer, Elsevier, and Frontiers publications:
- **Two Seminal Works:** Foundational classic papers establishing the theoretical bedrock and historical baselines.
- **Four Recent Works (2022–2026):** State-of-the-art advances in extended reality, machine learning, and human-computer interaction.
- **100% Active DOIs:** Every citation is verified via automated live CrossRef REST queries returning HTTP 200.

### 3. Non-Monetary Technoeconomic Formulations
In accordance with engineering pedagogy standards, all economic models avoid raw currency numbers. Instead, enterprise efficiency is evaluated using:
- **Dimensionless Cost Parity Ratio ($\kappa$):** Ratio of VR/AR recurring operational expenditure to physical baseline operational expenditure ($\kappa = \text{OpEx}_{\text{VR}} / \text{OpEx}_{\text{Physical}}$).
- **Institutional Labor Reclaimed:** Net annual student, instructor, technician, or clinician hours saved through digital automation.
- **Amortization Horizon:** Dimensionless capital payback period expressed in operating months.

## Student Git Submission & Branching Hygiene

### 1. Zero Direct Commits to `main`
The `main` branch is protected and reserved for verified, faculty-audited milestone releases.

### 2. Feature Branching Workflow
Every student works exclusively on their assigned personal feature branch:
```bash
# 1. Clone this repository
git clone https://github.com/MPSTME-Labs/NMIMS-MPSTME-IVRAR-2026.git
cd NMIMS-MPSTME-IVRAR-2026

# 2. Switch to your personal feature branch
git checkout -b feat/<your-roll-no>-<task-name>

# 3. Work exclusively inside your designated group directory
cd Group_XX_<Your_Names>

# 4. Stage and commit using Conventional Commits standard
git add .
git commit -m "feat(group-XX): implement spatial interaction telemetry logging"

# 5. Push your branch to GitHub
git push -u origin feat/<your-roll-no>-<task-name>

# 6. Open a Pull Request (PR) into 'main' via GitHub web UI
```
